Cómo se organiza el archivo

Las entregas se ordenan por año, mes, semana y fecha. Cada artículo vive en una carpeta con su propio index.html, de modo que GitHub Pages puede servirlo mediante una URL limpia.

Para recibir novedades por correo, añadiremos un formulario conectado a un proveedor de email cuando hayamos elegido uno. GitHub Pages sirve HTML estático, pero no almacena direcciones ni envía mensajes por sí mismo.
